# Pattern B 정책 초안

상태: Pattern B 활성 정책 버전 3에 반영됨 (2026-07-23)

이 초안은 Toss 증권 `snapshot_id=4`의 관측 종목과 사용자가 승인한 Pattern B 분류를 바탕으로 작성했다. 예수금 비중은 총 평가금액을 분모로 하고, Core·Satellite·Experiment와 개별 종목 비중은 투자금액을 분모로 한다. 따라서 세 레이어의 목표 합계는 투자금액의 100%다.

## 목표 구조

| 구분 | 최소 | 목표 | 최대 |
| --- | ---: | ---: | ---: |
| 예수금 | 10% | 15% | 20% |
| Core | 70% | 75% | 80% |
| Satellite | 15% | 20% | 25% |
| Experiment | 2% | 5% | 8% |

연간 계좌 수익률 목표는 10%이며, 측정 방식은 최근 365일 시간가중수익률(`trailing_12_month_twr`)이다. 관찰은 주간, 정기 점검은 월간으로 둔다.

## 현재 관측과 목표의 갭

`snapshot_id=4` 기준 현재 계좌는 평가금액 약 120,802,745원, 투자금액 약 120,796,725원, 예수금 비중 약 0.005%다.

| 구분 | 현재 | 목표 | 갭(목표-현재) |
| --- | ---: | ---: | ---: |
| 예수금 | 0.005% | 15.0% | +15.0%p |
| Core (투자금액 기준) | 48.3% | 75.0% | +26.7%p |
| Satellite (투자금액 기준) | 50.2% | 20.0% | -30.2%p |
| Experiment (투자금액 기준) | 1.4% | 5.0% | +3.6%p |

개별 종목의 목표·최소·최대 비중은 같은 디렉터리의 JSON 파일에 기록했고, 정책 버전 3으로 활성화했다. 현재 갭은 주문 지시가 아니라 다음 정기매수 정책을 조정하거나 예외적 개입을 검토할 때 사용하는 검사 신호다.

## 분류 원칙

- Core: SPY, VOO, QQQ, SCHD, KODEX200
- Satellite: AMZN, GOOGL, MU, NVDA, TSLA, GLD, 삼성전자, SK하이닉스, NBIS
- Experiment: SOXL, SPCX

SPY와 VOO의 지수 중복, 개별 위성 종목의 논지·중복·부담, Experiment의 레버리지·특수목적 노출은 활성화 전 확인 대상으로 남긴다. NBIS는 사용자의 정정대로 Satellite으로 반영했다.

2. 주간 관찰과 월간 점검에서 새 Toss 스냅샷을 기준으로 갭을 재계산
